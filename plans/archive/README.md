# 项目历史归档

本目录保存历史，不作为当前实现状态的默认依据。当前状态见 Wiki，活动工作见工作区任务清单。

## 分类

- `early-design/`：从项目根与 plans 根归位的原始错误技设计、引擎 v1 设计、旧植物路线图及图像移植文档。保留原文，当前规则以 Wiki/底账为准。
- `agent-notes/`：原 `.sisyphus/notepads/` 的阶段研究笔记，不作为 Agent 启动指令。
- `evidence/`：曾被 Git 跟踪的早期 validation 与默认场景运行日志；保留历史证据。新日志仍写入被忽略的 `artifacts/validation/` 或 `logs/`。
- 其余按专题/日期命名的目录：此前已经归档的阶段计划和决策推导，保留原有入口。
